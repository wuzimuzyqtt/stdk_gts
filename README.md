# GTS 0.3.0 (7 Days to Die V3.2)

缩小自己；任何人走过小人身上，小人会被踩碎：喷血、碎裂声、地上留一摊血（5 分钟后自动清理）。

## 安装
- 服务器和每个客户端都要把整个 `GTS` 文件夹放进 `Mods/`（还需要 `0_TFP_Harmony`，游戏自带）。
- 服务器 `serverconfig.xml`：`EACEnabled` 设为 `false`。
- 客户端用不带 EAC 的方式启动（启动器里取消勾选 EAC，或直接运行 `7DaysToDie.exe`）。

## 使用（F1 控制台）
| 命令 | 作用 |
|---|---|
| `gts shrink` | 缩小到 0.25 倍 |
| `gts shrink 0.5` | 缩小到指定倍数（0.01–0.9） |
| `gts grow` | 恢复原大小（头顶空间不够时会拒绝，先走到空旷处） |
| `gts speed 0.5` | 缩小时的移动速度倍数（0.01–3） |
| `gts speed auto` | 速度跟随体型（默认：0.25 倍大小 = 0.25 倍速度） |
| `gts status` | 查看状态 |
| `gts ray` | 调试：列出从当前视角开枪会打到什么 |

死亡后自动恢复原大小。

## 判定规则（服务器端，`Source/GtsMod.cs` 里的 `GtsConfig`）
- 踩踏者与小人水平距离 < 0.6m，脚底高度差在 -0.4m 到 +1.0m 之间，并且移动速度 > 0.8m/s。站着不动不会踩死人。
- 只有正常大小的玩家能踩人。把 `ZombiesCanStomp` 改成 `true` 后，僵尸也能踩。
- 伤害没有攻击者，所以不受服务器 PvP 设置影响。

## 编译
`sh Source/build.sh`（使用 VS 2022 Build Tools 自带的 Roslyn csc），输出 `GTS.dll`。改完代码后，要把新的 dll 同步到服务器和朋友的电脑上。

## 说明与限制
- 碰撞体随体型缩小，可以钻车底、栏杆缝、薄板下面；完整方块之间本来就没有缝，钻不过去。
- 台阶高度也按比例缩小，太小时上台阶需要跳。跳跃高度没有缩放。
- 碎裂效果用的是血雾粒子、血迹方块和音效，没有飞散的断肢模型。
