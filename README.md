# GTS 0.11.0 (7 Days to Die V3.2)

缩小自己；任何人走过小人身上，小人会被踩爆：僵尸啃食式的血浆喷溅、碎肉和头骨飞散、碎裂声，地上留一滩血迹（5 分钟后消失）。被踩死的尸体不会被僵尸啃食。

## 安装
- 服务器和每个客户端都要把整个 `GTS` 文件夹放进 `Mods/`（还需要 `0_TFP_Harmony`，游戏自带）。
- 服务器 `serverconfig.xml`：`EACEnabled` 设为 `false`。
- 客户端用不带 EAC 的方式启动（启动器里取消勾选 EAC，或直接运行 `7DaysToDie.exe`）。

## 使用（F1 控制台）
| 命令 | 作用 |
|---|---|
| `gts shrink` | 缩小到 0.25 倍 |
| `gts shrink 0.5` | 缩小到指定倍数（0.01–0.9） |
| `gts grow` | 恢复原大小（头顶空间不够时会拒绝，先走到空旷处） |
| `gts speed 0.5` | 缩小时的移动速度倍数（0.01–3） |
| `gts speed auto` | 速度跟随体型（默认：0.25 倍大小 = 0.25 倍速度） |
| `gts zombiestomp on` / `off` | 缩小时是否允许女性僵尸踩死你（默认关，每个玩家自己设置） |
| `gts status` | 查看状态 |
| `gts gore` | 在面前 2 米处预览一次爆浆效果（只有自己看得到，不伤害任何人） |
| `gts bloodtest` | 在面前从左到右排出 4 种血迹（01/02/05/06），2 分钟后消失，用来挑样式 |
| `gts stomptest` | 让最近的僵尸做一次踩踏动作（只有自己看得到），用来调动作 |
| `gts animinfo` | 只读：把最近僵尸的骨骼类型和动画片段列表写进日志 |
| `gts ray` | 调试：列出从当前视角开枪会打到什么 |

缩小状态会一直保留，死亡复活后仍是缩小的尺寸，输入 `gts grow` 才恢复。

## 判定规则（服务器端，`Source/GtsMod.cs` 里的 `GtsConfig`）
- 踩踏者与小人水平距离 < 0.35m + 小人半径，脚底高度在小人脚下 0.4m 到头顶上方 0.3m 之间，并且移动速度 > 0.5m/s。站着不动不会踩死人。
- 正常大小的玩家只能踩碎缩小到 0.3 倍以下的人（`PlayerStompMaxScale`）。
- 女性僵尸（按惨叫音效判断：Arlene、Darlene、Marlene、PartyGirl、Nurse、Lab、FemaleFat、Screamer）只有在小人自己打开 `gts zombiestomp on` 时才能踩：进入 1 米内她会抬起右脚踩下（代码驱动的骨骼动作），脚落下时小人还在脚下才会被踩死，抬脚期间跑开可以躲过。
- 男性僵尸（其余所有人形僵尸）只要碰到缩小的玩家（距离 ≤ 僵尸身体半径 + 小人半径 + 0.2m）就会被自动肢解（双臂、双腿、头），不需要移动，也不受开关影响，小人不会受伤。
- 服务器上也会缩小小人的碰撞体，僵尸才能真的走到小人身上。
- 伤害没有攻击者，所以不受服务器 PvP 设置影响。

## 编译
`sh Source/build.sh`（使用 VS 2022 Build Tools 自带的 Roslyn csc），输出 `GTS.dll`。改完代码后，要把新的 dll 同步到服务器和朋友的电脑上。

## 说明与限制
- 碰撞体随体型缩小，可以钻车底、栏杆缝、薄板下面；完整方块之间本来就没有缝，钻不过去。
- 台阶高度也按比例缩小，太小时上台阶需要跳。跳跃高度没有缩放。
- 爆浆效果全部使用游戏自带素材：血液粒子（僵尸啃食时的 `blood_eat`）、地面血迹（`groundDecalBlood02`，可在 `GtsConfig.BloodSplatVariant` 里换）、生肉块、僵尸断肢血肉、头骨模型。大小、飞散范围随被踩者的缩小倍数等比例缩放（最小按 0.1 倍算）；数量和基础大小在 `GtsConfig` 的 `Gore*` 参数里调。
